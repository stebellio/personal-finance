# personal-finance-webapp

Angular 16 frontend for the Personal Finance Tracker. See the [root README](../README.md) for project overview, architecture, and setup instructions.

## Quick commands

```bash
npm install
npm start                  # ng serve — http://localhost:4200
npm run build              # production build
npm test                   # Karma + Jasmine
```

The API base URL is configured in `webapp/environments/environment.ts` (`apiUrl`, defaults to `http://localhost:3000`).
